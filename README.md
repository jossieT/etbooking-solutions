# ETBooking Solutions Website

A modern, premium, enterprise-grade website for ETBooking Solutions built with Next.js, TypeScript, Tailwind CSS, and modern web development best practices.

## Overview

ETBooking Solutions specializes in developing custom booking and appointment management systems for service-based businesses including:

* Car Detailing Services
* Car Wash Businesses
* Barbershops
* Beauty Salons
* Healthcare Clinics
* Gyms & Fitness Centers
* Cleaning Services
* Professional Service Providers
* Educational Institutions
* Hospitality & Travel Businesses

This website serves as the company's digital presence, showcasing solutions, services, portfolio projects, pricing estimates, and consultation opportunities.

## Getting Started

### Clone Repository

```bash
git clone https://github.com/jossieT/etbooking-solutions.git
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

### Build Production Version

```bash
npm run build
```

### Start Production Server

```bash
npm run start
```
